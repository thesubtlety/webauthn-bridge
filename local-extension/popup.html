Connection and pairing

Optional broad HTTPS access avoids repeated permission confirmations for new providers and relay hosts. It grants this extension access to HTTPS sites; use only on a trusted browser and you can revoke it in Chrome extension permissions.

Connection settings are remembered even if a Chrome permission prompt closes this popup. For first-time setup, use the full Setup in a tab page. The relay host permission permits /health. Green also requires an encrypted peer ping.

Local authenticator preference

This is a WebAuthn UI hint, not a forced device selection. Chrome still enforces the site's credential restrictions.

Uses a small unfocused temporary window on remote for automatic sign-in. Chrome may still show or focus its WebAuthn prompt. Turn this off if the browser requires focus. Manual approval uses a visible tab.

Native mode detaches the proxy; retry the website's sign-in after switching. Already-intercepted requests cannot be handed back seamlessly.

Saved remote profiles (encrypted sync)

Only profiles with remote Quick-start consent can be preselected. Choosing a profile here cannot change its saved RP or signed origin.
