Identity-provider profiles

Profiles map exact RPs to authorized HTTPS signing origins. Automatic mode selects the sole or preferred matching rule; manual mode remains available.

Profiles are managed in the local bridge.

No separate approval popup, redirect checkbox, or injected “Use authenticator” button. A saved, unambiguous RP rule opens the remote IdP tab and asks Chrome for Touch ID / security-key consent. Unknown RPs and ambiguous profiles never auto-sign; choose Manual next login from the local extension if needed.

Connection and pairing

HTTPS site access is required at install for current and future profiles.

Connection settings are remembered even if a Chrome permission prompt closes this popup. For first-time setup, use the full Setup in a tab page. The relay host permission permits /health. Green also requires an encrypted peer ping.
